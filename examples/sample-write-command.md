# Sample Write Command

Paste into Gemini after binding the folder:

```text
[WRITE_FILE: QuAId/drafts/hello-from-gemini.md]
# Hello

This file was written through Braid Lens into the approved QuAId draft space.
[/WRITE_FILE]
```

Expected result:

```text
[WRITE_RESULT: QuAId/drafts/hello-from-gemini.md]
status: ok
bytes: 88
[/WRITE_RESULT]
```
